The shell around every site

Set in a web font loaded with @font-face from another origin, with the body in the engine's default sans.

Chitin is a web browser that runs inside a web page. Each site gets its own hard shell: a separate browser process with its own origin, its own copy of a real engine and its own storage.

Why a shell and not a mask

An interception proxy rewrites the sites it shows. It strips security headers, puts every site on one origin and edits scripts on the way through. Chitin does none of that: the site's bytes reach a real engine unmodified, and the engine's own network stack carries them. The name is the point. Chitin is what an insect's exoskeleton is made of: a shell around every site, rather than a mask over it.

“Sites Ganglion cannot render yet open in the user's own browser, never through a proxy.”

What this page exercises

  • a web font in the headings, fetched cross-origin and decoded by the engine (font/ttf);
  • italic and bold faces of the default family, like this and like this;
  • a float with text wrapping around it, a block quote with a border, and a list;
  • inline code, a link to another site, and a superscript1.
A pull quote floats to the right, and the paragraph text wraps around it as it should.

Layout here is LibWeb's: block and inline formatting, floats, margins collapsing between paragraphs, line boxes broken by the shaper with the fonts the host handed the engine. Painting is Skia's CPU rasterizer inside the same wasm module, which hands finished frames to the carapace as ImageBitmaps. Nothing on this page runs JavaScript, and nothing needs to.

monospace: 0123456789 abcdef — the engine's default fixed-width face.

¹ Phase 1: static pages only.
